# Backend delivery phases

Phase 0 — bootstrap Laravel skeleton, migrations, auth and CI; verify PostgreSQL + Redis connectivity.
Phase 1 — organizational hierarchy, staffing version, employee record and effective-dated assignment.
Phase 2 — personnel actions, approvals, private documents, leaves.
Phase 3 — calendars, absence rules, timesheets, training, candidate tracking and reporting.
Phase 4 — payroll (only after calculation specification and reconciliation), integrations and cutover.

For each phase: requirements traceability to `Кадры 2026`, API schema, policies, tests (positive, negative, cross-scope), audit and rollback.
